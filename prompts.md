# Registro de uso de IA · C.E.L.I.A.

Toda a saída das IAs foi revisada pela equipe antes de entrar no projeto.

**Sobre a redação:** em 18/11/2026, os prompts deste arquivo foram reescritos em linguagem técnica para facilitar a leitura. O conteúdo, a intenção e a ordem de cada pedido foram mantidos. Os resultados, números e decisões não foram alterados. O Python do projeto tem o próprio registro em `python-backend-IA/prompts.md`.
